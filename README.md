# Jedi Focus Timer

Star Wars temalı, sade bir pomodoro zamanlayıcı. Süre ilerledikçe Jedi'ın ışın kılıcı uzar:
odaklanırken mavi, molada yeşil yanar. Süre dolunca alarm çalar.

## Kullanım

- **START / PAUSE**: başlat, duraklat (`Space`)
- **RESET**: süreyi başa al (`R`)
- **FOCUS / BREAK**: mod değiştir (`F` / `B`)
- Süreyi değiştirmek için büyük saatteki dakikaya ya da alttaki kutulara tıkla

## Çalıştırma

```bash
npm install
npm run dev
```

## Teknolojiler

React, Vite, düz CSS. GitHub Actions ile GitHub Pages'e yayınlanır.
